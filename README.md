# Website Confession ♡

Website romantis sederhana, responsif, dan bisa dibuka dari HP. Tidak membutuhkan framework atau instalasi.

## Cara melihat di perangkat sendiri
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Untuk mengubah teks, buka `index.html` dengan editor teks lalu cari paragraf yang ingin diganti.

## Cara publikasi gratis lewat GitHub Pages
1. Masuk atau buat akun di https://github.com/
2. Buat repository baru. Contoh nama: `untuk-kamu`
3. Pilih **Public**, lalu buat repository.
4. Klik **Add file → Upload files**.
5. Upload `index.html` (boleh juga upload `README.md`).
6. Klik **Commit changes**.
7. Buka **Settings → Pages** pada repository.
8. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
9. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
10. Tunggu beberapa menit. Alamat situs biasanya berbentuk `https://USERNAME.github.io/REPOSITORY/`.

## Cara kirim ke WhatsApp
Setelah link GitHub Pages aktif, salin URL situs dan kirim seperti tautan WhatsApp biasa. Coba buka link dari HP lain atau mode incognito sebelum dikirim.

## Personalisasi yang disarankan
- Ganti kalimat surat agar sesuai pengalaman kalian sendiri.
- Kalau ingin menyebut nama, cari teks `Hai,` pada judul pembuka dan ubah sesuai kebutuhan.
- Tombol WhatsApp membuka WhatsApp dengan teks yang sudah disiapkan; penerima tetap bisa mengedit dan mengirim sendiri.
- Website tidak mengumpulkan jawaban atau data pribadi. Klik tombol jawaban hanya menyiapkan pesan WhatsApp, tidak mengirim otomatis.

## Catatan
Saya tidak dapat menerbitkan situs ke akun hosting milikmu secara langsung dari sini. Ikuti langkah GitHub Pages di atas untuk mendapatkan link publik gratis.
